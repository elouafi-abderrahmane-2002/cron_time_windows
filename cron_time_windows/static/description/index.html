Features

A frequency per time window

Each window runs the job at its own interval, in minutes or hours, or pauses it. Slots are aligned on the window start (08:00, 08:05, 08:10...), so the cadence never drifts.

Fixed times

Daily, weekly or monthly times, as many as you need. A job set on the 31st runs on the last day of shorter months.

Weekdays and night shifts

Limit a window to some weekdays, or let it cross midnight: a Friday 22:00-06:00 window covers Friday night until Saturday morning.

Your timezone, daylight saving included

Windows follow the wall clock of the timezone you choose, across summer time and Ramadan changes alike. The next execution is still stored in UTC.

Preview before you save

The form lists the next ten executions as you edit, and explains what is wrong when two windows overlap or the job would never run.

Many crons at once

Save reusable templates, then select crons in the list and apply a template, another cron's schedule, or one you define on the spot.

How to use it

  1. Open Settings > Technical > Automation > Scheduled Actions (developer mode) and pick a cron.
  2. In the new Time Windows tab, choose Time windows or Fixed times, and the timezone.
  3. Add your windows (start, end, run or pause, interval, weekdays) or your fixed times.
  4. Check the Next executions preview, then save. The next execution date updates at once.
  5. To set up several crons, select them in the list and use Actions > Apply Time Windows.

Good to know

  • Works on Odoo 16.0, Community and Enterprise. Depends on base only.
  • Opt-in per cron: every cron stays on Odoo's Native scheduling until you change it, so the mail queue, autovacuum and other core crons are never affected.
  • The cron itself keeps running: no extra dispatcher cron, and the scheduler's minute-level precision is kept.
  • A safety net skips a run that wakes up outside its window, or twice in the same slot, even when another module triggers the cron. Run Manually always runs.
  • Restricted to administrators; every rule is checked on the server.
  • Available in English and French.
